## 📌 Project Overview

**Stock Market Predictor & Analysis Dashboard** is a full-scale financial analytics project that integrates:

* 📊 Interactive Power BI dashboards
* 🤖 Machine Learning regression models
* 🧠 Deep Learning (LSTM) forecasting
* 📈 Time series analysis

The system analyzes historical stock data, extracts market intelligence, evaluates predictive models, and generates multi-horizon price forecasts.

The final output is an interactive, decision-support dashboard built in **Power BI**, along with predictive models implemented in **Python**.

🎥 A complete dashboard walkthrough video is included for demonstration.

---

# 🎯 Project Objectives

* Analyze historical stock price trends, volume, and volatility
* Identify market behavior and regime patterns
* Evaluate regression and ML model performance
* Forecast future stock prices using LSTM deep learning
* Enable company-to-company comparison
* Deliver clear financial insights via interactive dashboards

# 🚀 How to Run the Python Models

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/stock-market-predictor.git
cd stock-market-predictor
```

## 2️⃣ Create Virtual Environment

```bash
python -m venv venv
source venv/bin/activate   # Mac/Linux
venv\Scripts\activate      # Windows
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Run Notebook or Script

```bash
jupyter notebook
```

Open the ML/LSTM notebook and execute sequentially.
